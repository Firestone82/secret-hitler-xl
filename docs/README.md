# Developer docs

- [Running and deploying](running.md): run the site locally, build it, publish it to GitHub Pages.
- [Contributing](contributing.md): how to change rules text, roles or code and send a pull request.
- [Data files](data-files.md): the JSON files in `public/data/` that hold all the game text.
- [Print builder](print-builder.md): how the PDFs are put together, and the helper tools.

The site is an [Angular](https://angular.dev/) single-page app that runs entirely on static files. All game content lives in `public/`, so most changes are edits to JSON and need no code.
